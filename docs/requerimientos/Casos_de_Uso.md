# Casos de Uso

## Caso de Uso 1: [Nombre de la acción, ej: Iniciar Sesión]
- **Actor Principal:** [Usuario, Administrador]
- **Precondición:** El usuario debe estar registrado.
- **Flujo Normal:**
   1. El actor abre el sistema.
   2. El actor ingresa sus credenciales.
   3. El sistema valida la información.
   4. El sistema muestra el panel principal.
- **Flujo Alternativo:**
   - Si las credenciales son incorrectas, el sistema muestra un mensaje de error.

# Fase 03: Desarrollo de Software

## 1. Stack Tecnológico
- **Lenguaje:** Python 3
- **Framework Backend:** Flask
- **Base de datos:** SQLite (con esquema para PostgreSQL)
- **Frontend:** HTML, CSS, JavaScript.
- **Reportes:** Generación de PDF y Excel con librerías de Python.

## 2. Módulos implementados
- Módulo de autenticación y sesiones (`app.py`).
- Módulo de gestión de tickets y solicitudes (`app.py` y `database.py`).
- Módulo de reportes avanzados (`reports.py`).
- Módulo de administración de usuarios y categorías.

## 3. Código fuente
El código fuente completo se encuentra en:
- `app.py`
- `database.py`
- `reports.py`
- `templates/`
- `static/`

# Fase 05: Implementación y Despliegue

## 1. Guía de Instalación
Para ejecutar el sistema en local:
1. Instalar Python 3.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar el lanzador: `run.ps1` (en Windows) o `python app.py` en la terminal.

## 2. Credenciales de Acceso
- **Administrador:** admin@portal.local / Admin123!
- **Agente:** agente@portal.local / Agente123!
- **Cliente:** cliente@portal.local / Cliente123!

## 3. Entorno de Despliegue
El sistema está configurado para funcionar en un entorno local (localhost). El esquema de base de datos está listo para ser migrado a un servidor **PostgreSQL** en producción.
